# 自動ルール移行 & CSV取り込み・データ管理強化の実装計画

マネーフォワードのデータ特性（常に当年全期間が出力される点）に対応し、スムーズな月次運用を実現するための機能追加を行います。

## 追加・改善する機能

1. **自動ルールのエクスポート / インポート機能**
   - ルール設定モーダルに「エクスポート（JSONダウンロード）」と「インポート（JSON読込）」ボタンを追加。
   - 他のブラウザやバックアップからのルール復元を可能にします。

2. **CSV取り込み時の月選択 & 重複排除追加機能**
   - CSVファイル選択時に、含まれる年月（例: 2026-08, 2026-07...）を自動解析。
   - **取り込み対象の月**（「すべての期間」または「特定の月のみ」）を選択可能にする。
   - すでに編集中のデータがある場合、**「新規として読み込む（上書き）」** か **「既存データに追加する（重複排除付き）」** を選択できるようにする。
   - 重複判定ルール: 日付 + 金額 + 内容 + 金融機関 + MF_ID の完全一致で重複を自動スキップ。

3. **選択中月のデータ一括削除機能**
   - 期間セレクター（またはテーブル上部）に「表示中の月（〇件）を一括削除」ボタンを追加。
   - 誤って取り込んだ月や不要になった過去月のデータを安全に削除できます（確認ダイアログ付き）。

## 変更対象ファイル

### 1. `src/components/RuleModal.tsx`
- ルール一覧の下部に「ルールをエクスポート (JSON)」「ルールをインポート (JSON)」ボタンを追加。
- インポート時に「既存のルールに追加」または「上書き」を選択できるようにする。

### 2. `src/utils/csvParser.ts`
- レコードの重複排除判定ヘルパー関数（`mergeAndDeduplicateRecords`）の追加。
- CSVデータ内の年月一覧を高速抽出するヘルパー関数の追加。

### 3. `src/components/FileUploader.tsx` & `src/components/ImportModal.tsx`（新規）
- CSVをドロップした際、複数月が含まれている場合は「取り込み設定ダイアログ」を表示：
  - 取り込み対象の月（全期間 / 〇月のみ）
  - 既存データがある場合の取り込み方法（新規置換 / 重複排除して追加）

### 4. `src/components/PeriodSelector.tsx`
- 特定の月を選択している際に、「この月のデータを削除」ボタンを表示。

### 5. `src/App.tsx`
- 追加取り込み（重複排除）、選択月一括削除、ルールインポート/エクスポートの各アクションを統合。
